# Knowledge Press — 한 회차 실행 계약 v0.1

매회 최신 main의 이 파일과 README.md, 호출에서 명시한 프로젝트의 state.json을 읽는다. 프로젝트별 PROJECT.md가 지정되면 함께 읽고 그 범위만 적용한다. 프로젝트 미지정 시 임의의 프로젝트를 선택하지 않고 멈춘다. 목적은 지속되는 기계력을 독자의 이해로 압착하는 것이다. 직전 회차의 마지막 질문을 자동으로 이어가지 않는다.

1. state.phase가 completed이면 편집하지 말고 파일럿 종료를 짧게 알린다. state.revision은 완료한 회차 수다. 현재 작업 파일의 실제 내용과 최근 커밋을 확인하고 중복 회차 또는 충돌이면 멈춘다.
2. L3의 현재 결론과 L1–L2 개념·체인을 먼저 읽는다. README의 배분 제한을 적용한다. recent 기록에서 동일 연산 반복과 검색 횟수를 확인한다. 현재 핵심 설명을 가장 많이 변화시킬 연산을 하나 고른다. 목적과 선택 이유를 한 문장으로 말할 수 없으면 범위를 좁힌다.
3. explore 또는 외부 검색이 필요한 challenge는 원문·발표일·관측 기간·정의·근거 위치를 확인한다. 자료 추가가 아니라 특정 개념 또는 경쟁 가설의 판별을 목표로 한다. combine/transfer/compress/synthesize/prune/write는 기본적으로 외부 검색 없이 수행한다. 실제 내용 없이 가설을 사실로 승격하지 않는다.
4. 한 문장 결과를 만든다. 회차가 여러 개 쌓이면 문장들을 기존 논증 문단에 병합한다. 결합은 두 개념을 이어 붙인 문장이 아니라 그 조합에서 생기는 새로운 예측·조건·반례를 남긴다. 가설이 실패하면 수정·폐기한다. 억지로 새 이름을 붙이지 않는다.
5. L1–L3은 개념 압축 페이지의 해당 절을 수정한다. 중복 개념·체인을 정리하고 기존 ID는 재사용하지 않는다. 주요 근거와 반례를 잃지 않는다. L4는 이전 판보다 독자에게 명료하고 구체적인 시각을 제공할 때만 해당 문단을 교체·재집필한다. 같은 글을 요약해서 늘리거나 작업 보고서를 본문에 덧붙이지 않는다.
6. 외부 근거가 실제로 추가되면 L0 원고의 적절한 절을 기존 WIKI_PROTOCOL에 따라 증보·정정하고, 필요한 메타데이터·장부를 관리한다. 대화 증보를 수행하는 경우에만 해당 장부 절차를 따른다. 생성물은 직접 수정하지 않는다. L1–L4의 실험적 추론은 사실과 구분한다. 작업 범위는 state에 지정된 파일과 L0의 필요한 관련 원고에 한정한다.
7. 저장 전 최신 blob SHA를 다시 확인한다. 가능하면 변경 파일과 state를 한 커밋으로 main에 쓴다. 순차 쓰기라면 원고를 먼저, 상태를 마지막에 저장한다. 다음 회차는 원고에 이미 반영된 변경이 state에 빠진 경우 재적용하지 말고 실제 커밋을 보고 상태를 복구한다. 충돌은 덮어쓰지 않는다.
8. state.revision을 1 증가시키고 recent에 {run, op, external, result, changed, outcome}을 추가한다. result는 지적 변화 한 문장, changed는 실제 변경 파일 배열, outcome은 changed/no_change 중 하나다. 최근 6개만 보존한다. current_question과 current_thesis는 필요할 때만 갱신하고, retired_ids에는 폐기한 ID와 이유만 남긴다. 저장 실패·도구 장애는 성공 회차로 세지 않는다. 내용 변화가 없더라도 실제 사고 후 상태를 기록했다면 no_change 회차다. 20회째에는 phase를 completed로 바꾸고 첫 판과 현재 판을 비교해 짧은 평가를 state.review에 남긴다.
9. 저장을 재조회하고 커밋을 확인한다. 결과는 최대 5문장: 연산, 이전 설명에서 무엇이 바뀌었는가, 남은 검증 문제, 링크, 장애. 파일럿 종료 시에는 종합 평가를 보고한다. 이후 새로운 작업을 자의적으로 생성하지 않는다.

허용된 작업의 핵심은 자료 수집이 아니라 현재 지식 상태의 변화다. 자료가 한 건도 추가되지 않은 회차에도 설명이 달라질 수 있다. 새 통계, 새 방법론, 새 문서, 새 연구 이름을 의무화하지 않는다.
