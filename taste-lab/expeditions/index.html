무엇을 확인했나

생성 대수의 순서 의존성, 동일 씨앗의 재현성, 30개 씨앗의 형식 거리 변화, 가상 취향체의 A·B 비가환성, C 추가 시 기존 도달 경로 보존을 검증했습니다. DOM 환경에서 전 판본의 생성·감상·분기·내보내기 핸들러도 실행했습니다.

SVG를 렌더링해 작품의 격자·대칭·밀집·분산을 관찰했습니다. 브라우저 실행은 환경 제한으로 확인하지 못했습니다. 인간의 실제 취향 변화, 새 인식 차원, 모바일 레이아웃과 실제 다운로드 저장은 검증하지 않았습니다.

관찰에서 나온 다음 질문

형식 거리가 커져도 전부 같은 기하적 인쇄물로 보일 수 있습니다. 다음 계보는 생성 문법 자체를 바꾸고, 사람이 느끼는 동일성과 계산 거리의 충돌을 보존해야 합니다. C는 지금은 가정한 전이 규칙입니다. 실제 작품이 그런 전이를 만드는지는 별도의 연구입니다.
