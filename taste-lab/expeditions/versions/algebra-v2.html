생성 규칙과 이번 전시의 관찰

객체의 좌표·크기·형태를 바꾸는 실제 변형 g를 합성했습니다. 판정 함수의 덧셈·곱셈이 비가환적이라고 주장하는 실험이 아닙니다. 표시는 제작 순서이며 수학적 합성 표기에서는 역순입니다.

거리에는 요소 수·중심·반경·형태 비율·회전량만 사용합니다. 화면 밖 잘림이나 감상자가 느끼는 전체 인상을 이 수치가 보장하지 않습니다. 이 생성 문법은 원래 구상의 한 국소 실험입니다.
기반: 스타일 대수 §4–6 · 취향 계산기 ADAPTER §1–4. 생성 의도와 감상은 별개로 보관됩니다. 감상은 이 페이지 안에만 있으며 내보내기로 저장하세요.
