# 한 사람씩 — 인물 이미지 취향 탐사 v0.1

**실행 파일:** [index.html](./index.html) · 의존성 없는 단일 HTML/CSS/JS · 기존 [취향 실험실](../index.html)과 분리된 실험.

## 무엇을 경험하는가

화면에는 한 번에 **인물 이미지 한 장**과 세 선택(끌리지 않음 × / 궁금함 ◇ / 끌림 ♡)만 있다. 넘기기는 기록하되 선호로 취급하지 않는다. 좌우 스와이프, 위로 스와이프, 방향키와 되돌리기를 지원한다. 복잡한 수학과 작품 정보는 ⋯ 메뉴 뒤에 있다. 이유 설명, 점수, 좌표 선택은 요구하지 않는다.

이 실험의 관측 단위는 **완성된 이미지에 대한 전체적 반응**이다. 눈·의상·색을 따로 고쳐 가며 통제변수를 비교하는 실험이 아니다. 취향에 여러 국소 봉우리나 서로 다른 매력 체제가 공존할 가능성을 보존한다. 하나의 평균적인 미형으로 수렴시키는 최적화가 목적이 아니다.

## 이미지 공급의 실제 상태

- 기본 자료는 [Art Institute of Chicago의 Open Access 자료](https://www.artic.edu/open-access/open-access-images)를 공개 API로 받아온 인물 도판이다. **AI가 새로 생성한 캐릭터라고 주장하지 않는다.** 여러 시대와 매체의 인물 이미지는 초기 취향 탐사의 대체 표본이다.
- 자료를 가져올 수 없으면 이미지 추가 메뉴에서 사용자가 가진 이미지를 가져올 수 있다. 외부 이미지의 수집 및 표시 가능 여부는 통신 상태에 좌우된다.
- ⋯ → **새 캐릭터 생성 지시문**은 여러 인물 유형·나이·체형·기법을 섞는 16개의 총체적 장면 출발점과 최근 반응으로 이미지 생성 대화에 붙여 넣을 프롬프트를 만든다. 이는 **복사형 어댑터**이며 ChatGPT 이미지 API를 웹페이지에서 직접 호출하지 않는다.
- 생성된 이미지를 ⋯ → **내 이미지 넣기**로 추가하면 같은 인터페이스에서 계속 평가할 수 있다.

브라우저에서 직접 이미지를 생성하려면 별도의 인증된 서버/API 또는 독립 이미지 생성 모델이 필요하다. 이 저장소에 브라우저용 API 비밀키를 노출하지 않는다.

## 내부 계산과 다봉우리 가능성

후보 객체를 유한한 관측 표본으로 두고, 이미지를 평가한 이후에만 선호 신호를 학습한다. 특성 벡터는 **단일 미적 정답이 아니라 다음 탐색을 위한 저차원 대용물**이다.

1. 미술 도판의 **매체 6개 범주, 시대 5개 범주, 화면 종횡비**를 기록한다.
2. 브라우저 CORS가 허용하는 경우에만 **RGB 평균, 밝기, 대비, 채도, 온도 경향, 이미지 사분면 밝기, 거친 경계 밀도** 등 시각 신호 14개를 얻는다. CORS가 막히면 임의 값을 채우지 않고 해당 차원을 결측값으로 둔다. 총 슬롯 수는 26개이며, 여러 슬롯은 범주형 원-핫 표현이다. 이는 인간의 얼굴형·정서·서사감 등을 이해하는 의미 임베딩이 아니다.
3. 두 객체 사이 거리는 **공통으로 관측된 슬롯**에서만 계산한다. 유사도는 가우스 커널을 사용하되 서로 다른 매력 봉우리를 합쳐 하나의 중심점으로 강제하지 않는다. 끌림·거부·궁금함의 반응은 서로 다른 값을 갖고, 넘김은 선호 점수에 참여하지 않는다.
4. 다음 카드의 내부 우선순위는 (i) 근처의 국소 반응, (ii) 유사 이미지 노출을 통한 친숙함 가산, (iii) 반복 밀집에 따른 포화 억제, (iv) 관측이 적은 영역의 탐색으로 구성한다. 일부 카드는 **의도적으로 무작위 원거리 탐색**에 쓴다. 취향을 하나의 봉우리로 수렴시키지 않는 정책이다.
5. 친숙화·포화 항의 계수는 임시 휴리스틱이다. 이용자의 실제 감각이 시간에 따라 어떤 곡선을 따른다는 결과가 아니며, 반복 노출 실험이 없으므로 현재는 **포화 방지의 설계적 장치**이다. 진정한 과포화를 측정하려면 기간·재감상·동일 이미지/인접 양식에 대한 응답 변화를 별도로 기록·추정해야 한다.

상위 개념은 [FOUNDATIONS](../../wiki/taste-calculator-foundations.md), [수리취향학](../../wiki/mathematical-theory-of-taste.md), [어댑터](../../wiki/taste-calculator-adapter.md)를 참조한다. 이 실험은 셋을 교체하거나 축소하지 않는다.

## 조작과 데이터

- **화면:** 사진 한 장, ✕/◇/♡, 되돌리기, 그냥 넘기기.
- **키보드:** ← 거부, ↑ 궁금, → 끌림, Backspace 되돌리기.
- **숨겨진 메뉴(⋯):** 작품의 제목·출처, 지난 반응, JSON 내보내기, 새 이미지 추가, AI 이미지 생성 지시문, 구현 설명.
- **저장:** 사용자 평가는 브라우저 localStorage의 belorin-character-taste-v01에 보존한다. 사용자가 넣은 이미지는 축소해 같은 브라우저의 별도 키에 저장한다. 저장 용량 제한이 있고 **큰 이미지나 많은 파일은 실패할 수 있다**. 이미지 파일은 서버에 업로드하지 않는다.
- **내보내기:** JSON에 투표 시각, 사전 모델 점수, 작품/분석 메타데이터를 보존한다. 개인이 추가한 **이미지 파일 자체는 JSON에 들어가지 않는다**. 장기 이전을 원한다면 원본 이미지는 사용자가 따로 보관해야 한다.
- **안전:** 서버 계정·인증·이미지 생성 API 키는 없다. 공개적으로 제공되는 미술관 API 요청은 미술관 서버로 전송된다.

## 바로 실행하기

index.html을 웹 브라우저로 열면 된다. 온라인 상태여야 미술관 API 이미지를 받아올 수 있다. GitHub Pages에 게시될 경우 /taste-lab/characters/로 접근할 수 있다. 이 브랜치는 원본 실험실을 건드리지 않는다. 브랜치 자체는 GitHub Pages에 자동 게시되지 않으므로 미배포 상태에서의 호스트 미리보기는 외부 HTML 미리보기 서비스를 쓰거나 로컬에서 파일을 연다.

## 검증/남은 문제

- 정적 코드 검사: 세 선택, 스와이프/키보드/되돌리기, 투표 이전 사전 모델 점수, 로컬 저장, JSON 내보내기, 이미지 공급 경로를 확인했다.
- 실제 모바일 브라우저와 API/CDN의 실시간 응답 및 사람의 취향 변화는 검증하지 못했다. 도판이 실패하면 직접 이미지 추가 메뉴를 사용한다.
- 이미지 CORS가 차단되어도 **화면 표시를 재시도**하며 시각 특성 추출은 포기한다.
- 다음 확장: 실제 AI 생성 이미지 연결(안전한 서버 경유), 의미 임베딩을 포함한 객체 공간 학습, 장기 재노출에서의 친숙/포화 추정, 여러 국소 봉우리의 관측과 생성 품질 평가.

## 채팅 중심 L1–L3 장기 실험

실제 이미지 생성과 즉각적인 감상은 **ChatGPT 채팅에서 한 장씩** 수행한다. 이 브라우저 페이지는 보조 도구일 뿐 기본 실험장을 대체하지 않는다. L1 이미지·반응 → L2 가설·가중치와 노출 기록 → L3 명세·코드라는 세 층의 역할과 경계를 [L1–L3 연속 실험 프로토콜](./L1-L3.md)에 적었다. 재시작을 위한 [상태 스키마](./state.schema.json)와 [빈 템플릿](./state.blank.json)을 함께 둔다. 사용자 개인별 실제 데이터는 공개 위키에 자동 저장하지 않는다. ChatGPT의 자체 메모리에 정확한 수치를 강제로 넣을 수 있다는 전제도 쓰지 않는다.
