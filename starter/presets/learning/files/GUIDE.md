# 학습 노트 편집 지침

> [WIKI_PROTOCOL.md](./WIKI_PROTOCOL.md)에 더해 다음을 따른다. 이 위키의 원칙은 **베끼지 말고 자기 말로 다시 쓰기**다.

## 문서 유형

| 유형 | 쓰는 경우 | 틀 | 분류 |
| --- | --- | --- | --- |
| `course` | 과목·강의·교재 하나의 지도 | `templates/course.md` | 과목 |
| `concept` | 개념 하나의 설명 | `templates/concept.md` | 개념 |
| `problem` | 풀었거나 틀린 문제와 풀이 | `templates/problem.md` | 문제 풀이 |
| `review` | 스스로 답해 볼 복습 질문 묶음 | `templates/review.md` | 복습 질문 |

## 규칙

- 문서 ID: 과목은 `course-<영문>`, 개념은 `<과목>-<개념>`(예: `linalg-eigenvalue`), 문제는 `<과목>-p-<번호나 핵심어>`.
- 개념 문서는 교재 문장을 옮기지 않고, 처음 배우는 사람에게 설명하듯 쓴다. 직관 → 정의 → 예 → 흔한 오해 순서를 권한다.
- 교재·강의의 문제와 해설을 그대로 옮기지 않는다(저작권). 문제는 요지만 쓰고, 풀이는 자기 풀이를 쓴다.
- 문제 풀이에는 **처음에 틀린 이유**를 남긴다. 이것이 가장 값진 기록이다.
- 개념 문서의 `status`: `배우는 중`, `이해함`, `설명할 수 있음`. 복습 질문에 막힘없이 답하면 올린다.
- 과목 문서는 개념·문제 문서로 가는 목차 역할을 한다. 새 개념 문서를 만들면 과목 문서에 링크를 더한다.
