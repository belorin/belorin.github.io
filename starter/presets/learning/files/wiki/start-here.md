# 이 학습 노트를 시작하며

> {{name}}은 배운 개념을 자기 말로 다시 쓰고, 문제 풀이와 복습 질문으로 이해를 확인하는 공부 위키다.

## 이 위키가 하는 일

필기를 옮겨 적는 곳이 아니다. 배운 것을 **남에게 설명할 수 있는 글**로 다시 쓰고, 틀린 문제에서 무엇을 잘못 이해했는지 남긴다. 같은 개념을 다시 만나면 새 문서 대신 기존 개념 문서를 증보한다.

## 문서의 구성

- **과목:** 강의나 교재 하나의 지도와 목차.
- **개념:** 개념 하나의 직관, 정의, 예, 흔한 오해.
- **문제 풀이:** 풀이 과정과 처음에 틀린 이유.
- **복습 질문:** 스스로 답해 보는 질문 묶음.

## 읽는 방법

주제 목록에서 분류를 고르거나 검색한다. 쓰는 방법은 [공부 노트를 쓰는 방법](./learning-guide.md)에 있다.
