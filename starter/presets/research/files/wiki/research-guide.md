# 주장과 근거를 나누어 쓰는 방법

> 연구 노트의 가치는 무엇을 아는지보다, 왜 그렇게 아는지를 남기는 데 있다.

## 네 종류의 문서

**개념** 문서는 용어를 정의하고 비슷한 개념과 구분한다. **문헌** 노트는 한 편의 문헌이 무엇을 묻고 어떤 방법으로 무엇을 주장하는지 쓴다. **질문** 문서는 아직 답이 없는 문제와 가설, 단서를 모은다. **방법** 문서는 절차와 도구, 그것이 통하지 않는 조건을 쓴다.

## 근거의 종류

| 표시 | 뜻 |
| --- | --- |
| 문헌 | 이 위키의 문헌 노트와 그 절로 확인되는 것 |
| 관찰·데이터 | 직접 확인한 관찰이나 데이터 |
| 추론 | 위의 근거에서 논리적으로 끌어낸 것 |
| 가설 | 아직 근거가 없거나 부족한 것 |

## 관계로 잇기

문헌이 다른 문헌이나 개념을 뒷받침하면 `supports`, 반박하면 `challenges`, 같은 문제를 다르게 다루면 `contrasts`로 `wiki/relations.json`에 기록한다. 관계마다 그것이 드러나는 절(`evidence_section`)과 한 줄 이유를 적는다. 이 관계는 외부 AI용 색인 `ai/relations.json`에도 실린다.
