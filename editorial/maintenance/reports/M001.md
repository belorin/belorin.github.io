# 정비 보고서 M001

- 날짜: 2026-10-26
- 기준: 첫 정비
- 범위: 음악 분류의 초기 저밀도 원고 10편과 직접 연결된 원고만. 다른 분류·다른 음악 원고의 전면 점검은 수행하지 않음
- 읽은 문서: `jazz-to-ai`, `double-bass`, `electric-bass`, `rhythm-section`, `big-band`, `brass-band`, `drum-kit`, `jazz-dialogue`, `jazz-listening`, `silent-film`, `silent-film-musician-labor`, `jazz-ensemble-labor`, `jazz-live-quartet-case`, `jazz-history-plural`, `circus-music-questions`, `classical-canon-mauceri`

## 직접 고친 것
- `silent-film`을 `silent-film-musician-labor`에 통합. 전자의 큐시트·공연 장소에 따른 차이·서커스 비교를 후자에 흡수하고, 이전 앵커는 `linkAliases`로 보존
- `jazz-to-ai`는 공유 대화 링크와 경위 중심 안내를 제거하고 재즈 음악의 연주·편성·지역사·음향·노동을 연결하는 독립적 길잡이로 재집필
- `double-bass`, `electric-bass`, `rhythm-section`, `big-band`, `brass-band`, `drum-kit`, `jazz-dialogue`, `jazz-listening`의 기존 절을 보존하면서 전문 원고의 구체적인 구분과 사례를 증보
- `circus-music-questions`, `classical-canon-mauceri`, `SYNTHESIS.md`의 구 앵커 링크를 통합 문서로 갱신. `manifest.related`에서 삭제된 ID를 새 ID로 치환하고 별칭을 이관
- 외부 문헌을 새로 조사하지 않음. 기존 원고의 미검증 통계·일화는 미검증 상태로 유지

## 고치고 보고하는 것
- 독립 주제가 분명한 8개 악기·편성·청취·연주 개념 원고는 삭제하지 않고 심화. `jazz-to-ai`도 길잡이로 유지
- 기존 글과 후속 글의 설명이 겹치는 곳은 범위 차이를 분명히 함: 전문 항목은 정의·연주·악기의 세부, 종합 항목은 역사·노동·현장 사례
- 기존 공개 링크의 호환성을 위해 `#silent-film`은 통합 문서로 연결

## 결정 요청
