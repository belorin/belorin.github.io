# 실제 1원 수익 실험: AI 소액 의뢰 탐색·수행 운영 지침

목표는 AI가 작업을 통해 실제로 지급받은 순수익 1원 이상을 만드는 것이다. 공고 발견, 예상 매출, 가상 포인트, 미확정 현상금은 성과가 아니다. 24시간 같은 짧은 기한은 운영상 실험 조건이며 수익 보장이 아니다. 이 페이지는 매 회차 같은 플랫폼 조사와 가입 장벽을 되풀이하지 않도록 만든 실행 참조다.

## 1. 회차의 기본 절차

1. 이전 작업 기록을 먼저 읽는다. 현재 수익, 진행 중인 의뢰, 지급 조건, 실패 이유, 다음 행동을 확인한다.
2. 이전 후보를 무조건 다시 검색하지 말고 상태가 바뀌었거나 새로 등장한 의뢰를 확인한다. 새로운 시장은 소수만 시험하고 실제 의뢰 원문으로 내려간다.
3. 작업량·보상·현재 모집 상태·경쟁·발주 이력·AI 허용·권리·출금·권한을 검사한다.
4. 자격을 갖춘 후보가 있으면 작업 가능성을 작은 검증으로 입증하고 실제 해결·검증·제출용 산출물까지 전진한다. 제출은 계약·권한·플랫폼 규칙에 따라 승인된 범위에서만 한다.
5. 실수익을 증명할 지급 기록과 실제 비용을 확인한다. 성공하면 실험 종료, 미달이면 다음 회차에서 바꿀 행동을 기록한다.

지출 0원은 이번 유형의 실험 기본 가정이다. 이미 확보한 계산 자원도 경제적 비용이 될 수 있으므로 호출 시간·작업량과 추가 현금 지출은 따로 기록한다. 승인 없이 돈을 쓰거나 유료 가입, 계정 생성, 금융 거래, 개인정보 제공, 계약·외부 연락·제출을 하지 않는다. 권한이 필요한 경우 질문만 반복하지 말고 승인 후 바로 실행할 수 있는 결과물을 준비한다.

시장은 목록을 늘릴수록 유리한 것이 아니다. 무료 지원·보상 확실성·작업 가능성·현재 개방이라는 네 조건이 만나야 한다. 출금이나 신규 계정이 필요하면 완료가 아니라 구체적인 장애물로 기록한다. 시장 규정은 변하므로 실제 제출 전에 최신 조건을 확인한다.

## 3. 희소한 능력을 찾는 기준

일반 글쓰기와 코딩은 경쟁이 많다. 한국어·국문학·국내 데이터·소프트웨어가 결합되는 의뢰, 공개 PDF·HWP·CSV 변환, 공공기관 API와 자료 검색, MQTT·IoT·데이터베이스, 특정 실제 기기 환경의 검증은 자격이 맞는 경우에 비교우위를 기대할 수 있다. 사용자 현장 노동이 필요하면 별도로 구분한다. AI가 인간에게 요청하는 작업은 5분 $1, 15분 $5, 30분 $10, 1시간 $20이라는 예시 기준을 두고 실제 부담을 평가한다. AI만 수행하는 실험의 초소액 목표와 혼동하지 않는다.

지원 후보는 최신 공고, 지원 0~4명, 아직 면접 없음, 결제 인증, 양호한 고용·지급 이력, 명시된 분량, 낮은 지원 비용을 선호한다. 상대의 고용률 20%와 같이 표본이 작은 지표는 배제의 절대 규칙이 아니라 위험 신호다. 5명 미만은 0~4명이고 실제 자격 충족 인원은 모른다. 상세 검수 분량 미공개, NDA, AI 금지, 계정 설치·가입 요구, 데이터 제공권 불명확, 선불 구매 요구, 수익보다 큰 비용이 있다면 해결하기 전 진행하지 않는다.

대표적인 검증 문제는 국내 증권사 거래원 데이터다. 일반 주가 조회 성공을 거래원 데이터 성공으로 간주하지 않는다. 과거 특정 일자의 화면과 장기 누적 조회, 전체 거래시간 포함 여부, 합법적 재제공 조건을 확인해야 한다. 한국어 품질 검수라면 실제 분량, 평가 기준, 의미 보존, AI 보조 허용 여부를 확인한다. 계약 전 상당한 무료 작업을 요구하거나 외부 결제를 유도하는 공고는 피한다.

## 4. 수행 기록의 최소 형식

| 필드 | 기록할 것 |
| --- | --- |
| 회차·시각 | 시도한 시각, 기한 |
| 후보 | 플랫폼, 공고 제목과 원문 URL |
| 현재 상태 | 모집, 예치, 경쟁, 지급 이력 |
| 실행 | 검색이 아니라 실제로 검증·작성·시험·제출한 것 |
| 결과물 | 파일 또는 재사용 가능한 산출물의 위치 |
| 장애물 | 권한, 정산, 분량, 기술, 정책, 모집 종료 등 구체 원인 |
| 비용 | 추가 현금, 시간, 호출량은 구분 |
| 수익 | 실제 확정·지급 액수와 증빙 상태 |
| 다음 행동 | 다음 회차에서 가장 가치 있는 한 단계 |

동일 실패 원인을 반복하는 회차는 신규 시도로 세지 않는다. 조회 실패는 공고 부재와 다르고, 미확정 수익은 지급 증거가 아니다. 가능하면 실제 결제 확인까지 추적하되 개인정보와 결제 자격 정보는 공개 위키에 저장하지 않는다. 연구 기록에는 재현 가능한 일반 방법과 비식별 결과만 남긴다.

## 5. 첫 수익 이후

계약 성사율, 실지급까지 걸린 시간, 실제 작업시간, 현금 비용, 실패 원인을 비교한다. 첫 1원은 사업의 수익성이 검증됐다는 뜻이 아니다. 목표가 달성되면 추가 지출·거래를 중단하고 어떤 경로가 실질적으로 작동했는지 기록한다. 다음 실험에서는 순수익, 인간 개입 시간, 기계력 사용량을 함께 개선한다.
