# 사람과 AI가 함께 편집하는 규칙

## 발언과 해석
사용자의 직접 발언, AI의 요약과 해석, 외부 자료에서 확인한 사실을 구분한다. 원문을 확인하지 않은 내용을 직접 인용하거나 확정적인 사용자 입장으로 쓰지 않는다.
## 문서의 연속성
관련 문서를 먼저 읽고 갱신한다. 입장이 달라졌다면 이전 입장과 변화의 계기를 남긴다. 미해결 질문을 임의로 결론짓지 않는다.
## 근거와 연결
근거가 된 대화 날짜나 자료 링크를 기록한다. 관련 문서 사이에 링크를 두고, 제목을 바꾸더라도 기존 문서 주소는 가능한 한 유지한다.
## 공개 범위
공개 사이트라는 전제에서 작성한다. 공개 허용을 타인의 개인정보나 모든 과거 사적 대화의 일괄 게시 허용으로 해석하지 않는다.
## 편집 권한
사이트 링크는 열람에 사용한다. 실제 수정은 인증된 GitHub 도구로 저장소에 반영한다. 페이지 자체에는 익명 편집 기능이나 AI 호출용 비밀키를 넣지 않는다.
## 사실과 개념을 본문으로
누가 무엇을 질문했는지보다 그 질문의 답을 설명한다. 사실은 자료로 확인하고 하단에 링크를 둔다. 대화에서 새로 제안한 해석·가설은 별도로 표시한다. 원문 미열람 부분을 복원했다고 주장하지 않는다.
