# 기계력과 지식 압착 — 지속형 지식 생산 아키텍처 연구

세계에 정보가 흐르는 것만큼 기계적 지능이 흐르는 시대를 가정한다. 모델을 한 번 호출하는 행위는 일회적인 질의응답이기도 하지만, 외부에 남겨 둔 상태에 일을 가하는 한 단위의 기계력이기도 하다. 전기가 계속 공급되는 기계가 물을 퍼 올리거나 온도를 유지하듯, 일정한 간격으로 공급되는 지능은 어떤 지식 상태를 유지하고 변화시키는 데 사용될 수 있다.

이 연구의 목적은 **기계력이 누적될수록 인간이 읽어야 하는 양은 억제하면서 인간이 얻는 이해의 깊이는 증가하는 아키텍처**를 만드는 것이다. 자료의 수집·보존은 필요하지만 최종 산물이 아니다. 독자가 혼자서는 읽기 어려운 세계의 정보가 소화되어, 이전에는 존재하지 않았던 설명과 읽을 만한 글이 되어야 한다.

## 1. 기계력과 지적 노동

기계력은 여기서 물리적 에너지의 단위나 검증된 지능 척도가 아니라, 시간에 따라 이용할 수 있는 모델 호출·연산·도구·문맥 처리 능력을 통칭하는 설계 개념이다. 스케줄러는 이 자원을 간헐적으로 공급한다. 호출이 끊겨도 지식 상태는 외부 저장소에 남고, 다음 호출은 그 상태를 읽어 일을 이어 간다.

호출 수, 토큰 수, 실행 시간, 금전 비용은 서로 다른 자원이다. 동일한 호출 횟수라도 수행하는 연산의 가치가 다르다. 자료 검색, 긴 문헌 독해, 개념 결합, 반례 검토, 저술은 각기 다른 일을 한다. 기계력이 많아졌다는 사실만으로 더 많이 알게 되었다거나 더 잘 이해하게 되었다고 할 수 없다.

일반적인 문헌 조사에서는 기계력이 증가할수록 자료와 결과 문서가 늘어나기 쉽다. 검토되지 않은 글이 계속 생긴다면 독자의 독서 부채도 증가한다. 독서 부채란 아직 소화하지 못한 산출물을 읽고 비교하고 판단해야 하는 인간의 부담이다. 기계에게 일을 맡겼는데 그 결과를 다시 사람이 정리해야 한다면, 일부 노동이 인간에게 되돌아온 셈이다. 지식 압착은 이 방향을 뒤집으려는 시도다.

## 2. 압축과 압착의 차이

일반적인 요약은 원본 정보의 일부를 선택하고 길이를 줄인다. 압착은 그보다 더 강한 작용을 요구한다. 개별 사실을 공통 개념으로 추상화하고, 개념의 관계를 재구성하고, 그 관계로부터 새로운 설명이나 질문을 도출한다.

예를 들어 건설 대금의 지급 지연과 가계소득의 불규칙성을 각자 요약할 수 있다. 두 현상을 정해진 지출일과 불규칙한 수입의 충돌로 다시 읽으면, 기다리는 기간을 메우기 위한 신용 이용이라는 새로운 관측 대상이 나타난다. 기다림이 미래 소득에 대한 부채로 전환되는 과정, 즉 '시간의 부채화'라는 가설이다. 이 가설은 아직 관측된 인과관계가 아니지만 원래 자료를 다시 조사할 방향을 변화시킨다. [바닥경제의 개념 압축](./korea-bottom-economy-concept-compression.md)은 이러한 작용을 시험하는 첫 사례다.

따라서 압착에는 보존과 생성이 동시에 있다. 원래 증거는 남겨 두되 그 증거를 이해하는 표현은 바꿀 수 있다. 압착된 문장이 원래 문장의 단순한 교집합에 머무르지 않고, 결합에서 새로 생긴 설명을 포함할 수 있어야 한다. 다만 추론의 새로움과 사실의 확인, 학술적 독창성은 다른 판단이다.

## 3. 상태의 다층 구조

| 층 | 지식의 형태 | 주요 작용 |
| --- | --- | --- |
| L0 | 원문, 출처, 구체적 관측과 검증 | 수집, 정정, 보존 |
| L1 | 한 문장의 명제와 개념 | 추상화, 수정, 병합 |
| L2 | 압축 문단, 관계, 개념 체인 | 교차 결합, 전이, 반례 |
| L3 | 설명체계, 경쟁 가설, 잠정적 세계상 | 총합, 재구성, 폐기 |
| L4 | 인간이 읽는 독립적인 글 | 저술, 개고, 독서 밀도 개선 |

수직적으로는 조사 한 회차를 한 문장으로, 여러 회차를 한 문단으로, 여러 문단을 새로운 개념 체인으로 구성한다. 문단은 문장들을 이어 붙인 요약문이 아니라 이전 단계에 없던 관계를 드러내야 한다. 상위 설명에서 근거까지 내려갈 수 있는 경로는 유지한다.

수평적으로는 같은 층에 놓인 개념들을 서로 다른 분야로 이동시키고 충돌시킨다. 한 영역에서 설명력이 있던 개념이 다른 영역에서는 성립하지 않을 수 있다. 전이에서 드러난 차이가 개념을 더 정교하게 만들기도 한다. 이러한 수직 압착과 수평 순환은 한 번 끝나는 파이프라인이 아니라 반복되는 사고의 과정이다.

최상층 L4는 개념 그래프의 출력물이 아니다. 기계에게 읽기 좋은 구조와 인간에게 읽기 좋은 글은 다르다. 독자는 필요한 구체적 사례와 하나의 논리적 전개를 통해 세계를 이해한다. 작업 기록과 검증 장부를 본문에 모두 옮기는 대신 중요한 논증과 결정적인 근거를 자연스럽게 집필하고, 상세한 내용을 별도로 찾아볼 수 있게 한다.

## 4. 상태 변화로서의 연구

한 회차의 연구를 상태 S(t)에 연산 o(t)를 적용해 새로운 상태 S(t+1)을 만드는 일로 표현할 수 있다. 새로 들어온 증거를 E(t)라 하면 S(t+1) = F(S(t), o(t), E(t))이다. 이는 구현 계약을 설명하는 추상적 표현이며 계량적으로 측정된 모델은 아니다. E(t)가 비어 있어도 결합과 반증, 저술을 통해 상태가 변할 수 있다.

| 연산 | 지적 결과 |
| --- | --- |
| 탐사 | 특정 질문을 판별할 새 증거 |
| 압축 | 여러 사실을 설명하는 명제 |
| 결합 | 개념들의 관계에서 생긴 설명·예측 |
| 전이 | 다른 영역에서의 적용 조건과 반례 |
| 반증 | 기존 개념의 범위 수정 또는 기각 |
| 총합 | 설명체계의 재편 |
| 망각 | 중복 개념과 불필요한 질문의 퇴역 |
| 저술 | 독자에게 전달되는 이해의 개선 |

연산 선택은 직전 회차의 마지막 질문에서 자동으로 시작하지 않는다. 현재의 설명체계와 연구 목적을 먼저 읽고 가장 값어치 있는 변화가 무엇인지 판단한다. 외부 검색은 모든 회차의 전제 조건이 아니다.

망각은 증거를 파괴하는 일이 아니다. 활성 상태에서 역할을 끝낸 개념을 제거하고, 필요하면 과거 판으로 돌아가는 일이다. 문서의 과거를 Git에 보존하되 현재판이 모든 과거의 논쟁을 반복할 필요는 없다. 장기적으로는 상위 개념의 재편과 하위 증거로의 재하강 비용을 어떻게 제한할지 연구해야 한다.

## 5. 접선적 발전과 기계력의 배분

초기 프로젝트에서 두 실패 유형이 나타났다. 바닥경제는 계속 통계를 조사하며 자료가 쌓였고, 국제기구 보고서의 교차 탐사 설계는 새로운 검증 절차가 또 다른 검증 문제를 낳으면서 방법론이 길어졌다. 전자는 개념적 압착을, 후자는 실제 발견을 충분히 수행하지 못했다. 관련 원고는 [2026, 바닥의 경제](./korea-bottom-economy-2026.md)와 [읽히지 않은 보고서들의 교차점](./cross-institutional-report-discovery.md)이다.

직전 문제에서 파생되는 다음 문제를 풀 때 국소적인 논리는 유지되어도 전체 목적을 향한 진전은 없을 수 있다. 이를 연구의 접선적 발전이라 부른다. 방법론 연구 역시 같은 실패에 빠질 수 있다. 방법을 개선하기 위한 조사는 관찰된 실패나 실제 실험에서 출발해야 하며, 다음 설계 문제가 있다는 이유만으로 새 절을 계속 추가하지 않는다.

기계력의 배분에는 두 층위가 있다. 첫째는 한 연구 안에서 자료 조사와 내부 사고, 저술 사이에 배분하는 일이다. 둘째는 여러 연구 프로젝트 사이에 배분하는 일이다. 현재 구현은 각 프로젝트의 스케줄을 독립적으로 설정하고 최근 회차의 연산 비중을 제한한다. 향후에는 자료가 충분한 연구, 설명의 충돌이 큰 연구, 독서용 원고의 개선이 필요한 연구가 서로 다른 양의 기계력을 필요로 하는지 시험할 수 있다. 호출과 토큰을 하나의 고정 가치로 환산하지 않는다.

## 6. 읽기 비용을 성능의 중심에 놓는다

예컨대 100회의 조사에서 100페이지의 결과가 나오는 경우와, 같은 100회의 조사에서 10페이지의 잘 쓰인 글이 만들어지는 경우를 비교한다. 전자가 더 충실한 증거 저장소를 가질 수 있지만, 독서층에서는 후자가 더 높은 설명력을 지향한다. 분량을 줄였다는 이유만으로 성공이라 할 수 없고, 짧은 문장이 근거를 잃거나 과도한 일반화를 만들었다면 실패다.

평가의 핵심은 같은 독서 시간에서 무엇을 추가로 이해할 수 있는가이다. 이전 판에 없던 설명, 서로 떨어져 있던 개념의 결합, 반례에 따른 수정, 구체적 근거로 돌아갈 수 있는 정도, 독자의 실제 이해와 흥미를 함께 본다. 이를 하나의 객관적 점수로 환원하지 않는다. 모델이 자신의 글이 더 좋아졌다고 평가하는 것과 독자가 실제로 더 잘 이해하는 것도 구별해야 한다.

실험할 때는 같은 주제·같은 시작 자료에서 단순 증보 방식과 순환형 압착 방식을 비교하고, 가능한 한 비슷한 기계력과 독서 분량 조건을 둔다. 이때 새 자료가 없는 회차에서 설명이 발전하는지, 새 자료가 기존 결론을 뒤집는지, 더 짧아진 글이 실제로 더 나은지 관찰한다. 실험 조건과 실제 결과를 분리한다.

2026년 11월 25일에 두 프로젝트를 독립적인 상태로 구성했다. 공통 실행 계약은 [README.md](https://github.com/belorin/belorin.github.io/blob/main/design/knowledge-press/README.md)와 [RUN.md](https://github.com/belorin/belorin.github.io/blob/main/design/knowledge-press/RUN.md)이다. 이 연구 페이지는 설계의 발전과 비평을 기록하는 공간이며, 실행 계약 자체가 아니다.

| 프로젝트 | 독서층 | 개념층 | 증거층 |
| --- | --- | --- | --- |
| 바닥경제 | [생활을 지속할 수 있는 시간](./korea-bottom-economy-reading.md) | [개념 압축](./korea-bottom-economy-concept-compression.md) | [기존 조사 원고](./korea-bottom-economy-2026.md) |
| 세계 보고서 | [세계를 다시 읽다](./world-report-reading.md) | [교차 발견](./world-report-concepts.md) | [보고서 근거](./world-report-evidence.md) |

현재 초기 정책은 프로젝트별 20회 파일럿, 최근 6회 중 외부 탐사 최대 2회 및 외부 검색 전체 최대 3회, 동일 연산 3회 연속 금지, 활성 개념 기본 20개와 체인 8개, 독서본 6,000자 상한이다. 이는 최적화 결과가 아니라 초기 가설이다. 두 프로젝트가 실제로 이 규칙을 지켜 어떤 결과를 만들어 내는지는 회차 이력과 원고의 변화로 확인해야 한다.

이 글의 최초 작성 시 저장소에서 두 프로젝트의 revision 0을 확인했다. 자동 실행의 연구 성과는 아직 관측하지 않았다. 따라서 이 시점에는 지식 압착의 효과를 입증할 결과가 없다.

## 8. 스케줄러에서 API 실행기로

지식 상태, 연구 연산, 실행 장치를 분리한다. 현재 스케줄러는 주기적으로 모델을 깨우고, 모델은 GitHub에서 최신 상태를 읽어 변화시킨다. 앞으로 API로 옮기더라도 연구 상태와 연산의 의미를 유지한다.

최소 인터페이스는 상태 읽기(read_state), 변화 제안(propose), 검증 및 적용(apply)이다. 실행기는 모델의 결과를 곧바로 정본으로 덮어쓰지 않고 읽은 판본과 최신 판본을 대조한다. 원자적 커밋, 회차 중복 방지, 실패 복구, 변경 검증은 실제 실행의 문제로 남아 있다. 현재는 프롬프트와 GitHub를 이용한 파일럿이며 독립 API 서비스는 구현하지 않았다.

API 실험에서는 모델별 역할과 연산별 비용을 바꾸어 볼 수 있다. 문헌 탐사·근거 추출·개념 결합·독서용 저술에 모두 같은 모델을 쓸 필요는 없지만, 역할을 나누었을 때 실제로 더 좋은 결과를 얻는지도 검증할 문제다. 복잡한 에이전트 조직의 설계가 연구를 다시 대체하지 않도록 작은 실행기에서 출발한다.

## 9. 앞으로의 연구 문제

- **의미 밀도와 압착 한계:** 중요한 정보와 반례를 잃지 않으며 얼마나 압축할 수 있는가? 독자가 받아들일 수 있는 분량은 주제와 장르에 따라 어떻게 다른가?
- **개념의 생태:** 개념이 결합·전이·경쟁하며 성장하고 퇴역하는 과정에서 의미 있는 발견과 이름의 증식을 어떻게 구별하는가?
- **기계력 배분:** 신규 탐사와 내부 순환의 적절한 비율은 어떻게 변하는가? 연구가 정체되거나 같은 결론을 반복할 때 어떤 연산으로 전환해야 하는가?
- **다층 기억의 장기 지속성:** 만 회차 이후에도 전체를 읽지 않고 현재의 설명과 필요한 근거를 재구성할 수 있는가?
- **독자의 평가:** 동일 독서 시간에서 실제로 이해가 개선되었는지 어떻게 관찰하는가? 독자의 관심 변화는 압착 방향에 어떤 영향을 주는가?
- **API 실행과 실험:** 스케줄러와 API, 모델·예산·연산 배치의 차이를 실제 결과로 비교할 수 있는가?

이 질문들은 순서대로 연구해야 하는 자동 대기열이 아니다. 두 파일럿에서 발생한 실제 현상과 실패를 보고 가장 중요한 문제를 선택하고, 가능한 작은 비교 실험을 수행한다. 연구의 현재 설명은 결과에 따라 수정·병합하며, 새 방법론 문단을 추가하는 것 자체를 성과로 삼지 않는다.

*초판: 2026년 11월 25일. 현재까지의 설계 논의와 저장소 구현을 총합한 연구 원고. 외부 선행연구를 새로 조사하거나 파일럿 효과를 실증하지 않았다.*
